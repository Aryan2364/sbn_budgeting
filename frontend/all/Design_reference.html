2. Type scale

Seven slots. Hierarchy comes from size, weight and colour moving together, never from size alone. Watch how the weight drops from 500 to 400 and the colour fades as the size shrinks.

Body · 14 / 400 / 1.6 — the default for all normal reading text.

Body strong · 14 / 500 — active nav, emphasis, table totals.

Label · 13 / 400 — always text-secondary, never text-primary.

Meta · 12 / 400 — timestamps and counts only. Never a price or a status.

4. Buttons

One primary per screen. Everything else secondary. Height is fixed at 36px regardless of label length, which is why the same action is the same size on every page.

Icon buttons

Every icon-only button has a filled background, a border, and a 36 by 36 hit area. A transparent icon with no border is not a button, it is decoration the user cannot find.

One primary fill, the rest neutral, danger only for delete. Hover over each to see the tooltip.

5. Messages

Toast for confirmations, inline for field errors, banner for ongoing conditions, dialog for destructive actions. Every message carries an icon as well as a colour, because colour alone is invisible to colour-blind users.

Toast — success

Invoice INV-1001 saved

Banner — error

Could not connect to the server

Check your internet connection and try again.

Inline field error

rakesh@rgbindia

Enter a complete email address, like name@company.com

Error text states the cause, then the next action. No exclamation marks, no "Error:" prefix, no raw technical messages.

6. Text overflow

Text never overflows its container. Which of the three behaviours applies depends on the container, not on the text.

13. Empty, loading and destructive states

Three empty states, not one. Offering "Add your first client" to someone whose filter simply matched nothing makes the software look unintelligent.

🔍

Skeleton while loading

Never a spinning wheel. The layout arrives first, so the page does not jump when data lands.

Delete Umbrella Ltd?

This will also remove 4 invoices and 3 open tasks. This cannot be undone.

A confirmation that does not state the consequences is not a confirmation, it is a speed bump. Name what is being deleted and what else it affects.
